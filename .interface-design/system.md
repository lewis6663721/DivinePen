# 视觉系统 · DivinePen

> 方向已定，此处记录的是**决策**，不是建议。后续所有页面按此执行，偏离需先改这里。
> 样张：`design/specimen.html`（`make specimen`）

---

## 1. 意图

**人**：一个人同时管着模型、密钥、任务和账单的开发者 / 内容负责人。他开着十几个标签页，
在等一条视频渲染完，顺手想知道今天烧了多少钱。他烦躁、着急，而且**怕点错花冤枉钱**。

**任务**：看清"现在能跑什么"、把一次贵的调用安全地发出去、在任务队列里找到卡住的那条。

**感觉**：机房里的一台仪器 —— 安静、精确、耐看。数字有分量，钱有颜色，就绪状态会发光。
不是办公后台的塑料感。

---

## 2. 方向：石墨调色台（Graphite Console）

### 与「分镜系统」的区隔（刻意为之）

| | 分镜系统（agent_drama_storyboard） | DivinePen |
|---|---|---|
| 底 | `#f4f7fb` 浅蓝灰 | `#0d1014` 石墨 |
| 强调 | `#2563eb` 蓝 | `#2fcfb2` 信号青 |
| 隐喻 | 办公后台 / 表格 | 渲染机房 / 仪器 |
| 数据字体 | 继承正文 | 全部走等宽 |

两者本就是不同世界的工具。长得像才是设计失误。

### 被拒绝的默认路径

- 浅底 + 蓝强调（通用 SaaS 脸）→ 石墨 + 信号青
- 卡片三件套阴影 → 深色下阴影读不出来，改用边框 + 亮度跳档
- 每个能力分类配一个颜色 → 一片彩虹、焦点涣散。**颜色只回答"能不能用"**
- `--gray-700` / `--surface-2` 这类匿名令牌 → `--inset` / `--billing` / `--signal` 有语义

---

## 3. 令牌

### 表面（只动亮度，不动色相）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--canvas` | `#0d1014` | 页面底 |
| `--surface` | `#151a20` | 卡片 / 面板 |
| `--surface-2` | `#1c2229` | 浮层 / 悬停 |
| `--surface-3` | `#232a32` | 胶囊 / 选中态 |
| `--inset` | `#0f1318` | **输入框比周围更暗**——它是凹进去接收内容的 |

相邻两级肉眼几乎分辨不出，叠起来层次自然浮现。

### 分隔（低透明度 rgba，不用实心 hex）

`--line-soft` `.045` · `--line` `.075` · `--line-strong` `.14`

### 文字（四级，层级靠 字重 × 明度）

`--ink` `#e9eef4` 值 · `--ink-2` `#a7b2bf` 标签 · `--ink-3` `#6d7885` 元信息 · `--ink-4` `#4a5461` 禁用

### 语义色（每个只有一件事要表达）

| 令牌 | 值 | 唯一含义 |
|---|---|---|
| `--signal` | `#2fcfb2` | 就绪 / 可执行 / 连通。**全站唯一强调色** |
| `--billing` | `#e8a33d` | 需要支付代价：计费参数、金额、警告 |
| `--ok` | `#3fbf7f` | 成功终态 |
| `--danger` | `#e5484d` | 失败 / 破坏性操作 |

计费与警告共用琥珀是一个**刻意的语义合并**：两者都是"这里要你付出代价"。

## 4. 排版

- 无衬线：`ui-sans-serif` 栈 + `PingFang SC`（中文必须显式声明，否则 macOS 上会掉到宋体）
- 等宽：`ui-monospace` 栈。**凡标识符与数字一律等宽 + `font-variant-numeric: tabular-nums`** ——
  模型名、`task_id`、金额、时长、分辨率。对不齐会显得很脏。
- 字阶比例 1.25，基数 14px：

| 用途 | 字号 / 字重 | 令牌 |
|---|---|---|
| 页面主标题 | 33 / 600 | `display` |
| 区块标题 | 21 / 600 | `h2` |
| 卡片标题 | 17 / 600 | `h4` |
| 正文 | 14 / 400 | `body` |
| 表单标签 | 13 / 500 | `label` |
| 元信息 | 12 / 400 | `meta` |
| 小节标签 | 11 / 500 + `.09em` 字距 + 大写 | `micro` |
| 数据 | 14 / 500 mono | `data` |

大字级加负字距（`display` −.022em），正文行高 1.55。

---

## 5. 空间与圆角

- 基数 **4px**，只用倍数：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`
- 密度取**紧凑档**（控制台，不是宣传册）：面板内边距 20px，行内 12px
- 圆角三档，不混用：控件 **6** · 卡片 **10** · 浮层 **14**
- 嵌套圆角：`外 = 内 + padding`

---

## 6. 深度策略（只选一种，贯彻到底）

**边框 + 亮度跳档，零阴影。**

深色下阴影读不出来，只会让画面发灰。层次靠 `--line` 系列 + 表面亮度递进表达。
唯一的例外是 `--signal` 的聚焦光环 `box-shadow: 0 0 0 3px var(--signal-dim)`。

---

## 7. 三个签名元素

### ① 能力节点（`.cap`）
- 左侧 2px **状态轨**：`ready` 青 / `need-key` 琥珀 / `off` 灰
- 分类用等宽文字（`video.t2v`），**不用颜色**
- 底部 chip 胶囊：`就绪` / `async` / `按秒计费` / `ffmpeg`
- 扫一眼就能从几十个能力里挑出"现在能跑的"

### ② 计费仪表（`.billbar`）
- 影响计费的参数（时长 / 分辨率 / 张数）带琥珀点 `<i class="dot-bill">`
- 表单底部单独一条计费栏，**改参数即刻重算**
- 主按钮文案直说金额：`花费 ¥1.40 生成`，不写"提交"
- 这是对"怕花冤枉钱"这个人性弱点的正面回应

### ③ 任务胶片格（`.filmstrip`）
- 一格 = 一次轮询。已完成青色，当前在跑的那格呼吸（`prefers-reduced-motion` 下关闭），失败格变红并**停住**
- 视频任务要跑几分钟且轮询有固定节拍，细进度条表达不了"卡在第几次"
- 失败格原位变红 → 一眼定位故障点

## 8. 组件规格

| 组件 | 规格 |
|---|---|
| Button 默认 | 高 34 · 内距 9/14 · 圆角 6 · 13px/500 · `--surface-2` 底 |
| Button primary | `--signal` 底 + `#06231f` 字（深青字在亮青底上对比度才够）· 600 字重 |
| Button `:active` | `transform: scale(.97)`，绝不小于 .95 |
| Input / Select | `--inset` 底 · `--line` 边框 · 圆角 6 · 内距 9/11 · focus 时 `--signal` 边框 + 3px 光环 |
| 胶囊 chip | 10.5px mono · 内距 4/7 · 圆角 4 · `--surface-3` 底 |
| 面板 panel | `--surface` 底 · 1px `--line` · 圆角 10 · 头部下边框 `--line-soft` |
| 分段控件 seg | `--inset` 轨道 + 3px 内距，选中项 `--surface-3` + 内阴影 |
| 状态 chip | 底/字/边三者同色系低透明度（`--signal-dim` / `--billing-dim` / `--ok-dim` / `--danger-dim`） |

**命中区**：所有可点元素 ≥ 40×40（胶囊、图标按钮用伪元素向外扩）。

---

## 9. 动效

- 时长 < 300ms。交互反馈 100–160ms，浮层 150–250ms
- 缓动 `cubic-bezier(.23,1,.32,1)`，**绝不用 ease-in**
- 只动 `transform` / `opacity`，不写 `transition: all`
- 出现从 `scale(.995)` + `opacity 0` 起，绝不从 `scale(0)`
- 高频操作（快捷键、命令面板）**不加动效**
- `prefers-reduced-motion` 下保留透明度变化，去掉位移与呼吸

---

## 10. 状态是必需品

每个交互元素：默认 / 悬停 / 激活 / 聚焦 / 禁用。
每份数据：加载 / 空 / 错误。空态必须**给出下一步动作**，不能只写"暂无数据"。

---

## 11. 自查

- **替换测试**：把等宽数据、状态轨、琥珀计费栏换成普通样式 —— 这页立刻变成任何一家后台 ✗
- **眯眼测试**：只有"今日花费"和就绪轨道浮出来，没有刺眼分割线 ✗
- **签名测试**：能点出五处签名落点（状态轨、计费栏、胶片格、琥珀点、等宽数据）✗
- **令牌测试**：`--signal` `--billing` `--inset` `--canvas` 只可能属于一个"渲染 + 计费"产品 ✗
